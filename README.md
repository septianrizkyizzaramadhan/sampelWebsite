# Sampel Website Freelance

Kumpulan demo website yang siap dijual dan dikustomisasi untuk klien.

## Daftar Project:
1. **`laundry-demo/`** — Website Laundry (Next.js, TypeScript, Tailwind CSS)
2. **`kopi-senja-solo/`** — Website Kopi (Next.js)

## Cara Menjalankan Salah Satu Project
1. Masuk ke foldernya: `cd laundry-demo`
2. Install dependencies: `npm install`
3. Jalankan: `npm run dev`
