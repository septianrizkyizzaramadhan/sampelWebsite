## 🇮🇩 Bahasa Indonesia

Kumpulan proyek website demo yang dikembangkan sebagai portofolio freelance. Website dirancang untuk kebutuhan bisnis dan dapat dikustomisasi sesuai kebutuhan klien.

### Project Showcase

- **Laundry Website** — Website bisnis laundry menggunakan Next.js, TypeScript, dan Tailwind CSS.
- **Kopi Senja Solo** — Website coffee shop untuk promosi dan branding bisnis.

### Menjalankan Project

```bash
git clone https://github.com/septianrizkyizzaramadhan/sampelWebsite.git
cd sampelWebsite/laundry-demo
npm install
npm run dev
```
