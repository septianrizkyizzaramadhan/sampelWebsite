# CleanWave Laundry — Professional Business Website

Website *landing page* modern dan responsif untuk bisnis laundry. Dibuat dengan fokus pada performa, desain premium, dan kemudahan kustomisasi untuk berbagai klien.

## 🚀 Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Font:** Lora (Serif) & Geist (Sans-serif)
- **Deployment:** Vercel

## ✨ Fitur Utama
- Desain *Mobile-First* yang responsif (Mobile, Tablet, Desktop).
- Navigasi *sticky* dengan menu mobile yang mulus.
- *Hero section* dengan foto *full-screen* dan *overlay* elegan.
- Daftar layanan dan paket harga yang terstruktur.
- Integrasi tombol WhatsApp otomatis (pesan langsung terisi).
- Animasi dan transisi halus tanpa mengorbankan performa.
- Struktur kode modular (komponen terpisah per section).
